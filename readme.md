# ZE.Utils - разнообразные утилиты
# Содержание

## LRU Buffers
Списки с хранением времени создания элемента. При переполнении емкости начинает записывать на место самого старого элемента.

## Pooling
База для пулов на основе Unity.Pool. Предоставляют интерфейсы для объектов пула и релизеров - объектов, занимающихся возвратом элементов обратно в пул. Утилиты создавались для удобства создания дженерик-пулов (например разнообразных vfx-эффектов)

## Processes
База для создания менеджера процессов - объекта, который создает и отслеживает прогресс процессов - длительных вычислительных операций. Менеджер может запускать сразу несколько процессов. Сам по себе менеджер не обновляется - он работает только по внешним запросам. В комплекте два абстрактных класса - для процессов, запускающих job и просто для асинхронного функционала.

## Shrinking List
Список из подобранных вариантов, который уменьшается по мере извлечения из него. Используется в основном для создания рандомных подборок и извлечения по random value. Может быть восстановлен через RestoreAllItemsAsActive()

## AwaitablesExtensions
Добавляет аналоги UniTask.WhenAll для Unity.Awaitables

## ByteCoder 
Пишет и читает значения из потока байтов

## DelayedOneShotSubject
Аналог ReactiveProperty, но не посылает дефолтное значение. Рассылает в observable только когда значение будет установлено, а затем сразу удаляется.

## EditorPlaymodeLifetimeObject
Синглтон-объект, который отслеживает момент выключения плеймода.

## ExtendNativeCollectionCommand
Заменяет коллекцию на более вместительную если нужно, иначе - возвращает очищенную или неизмененную обратно. 

## MathExtensions
Добавляет аналоги некоторых функций Mathf (например MoveToward) для Unity.Mathematics данных. Также имеет функцию для вращения с ограничением.

## MessageBroker
Аналог MessageBroker из UniRx для R3

## StringExtension
Добавляет методы для подготовки имен addressable-ассетов в snake_case
